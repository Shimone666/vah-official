# Nika Composer (public demo)

Simplified public version of Nika Composer for **Nika VAH**.

- No production / private workshop data
- Timestamp lock chain removed — slot duration + `[chord][prompt]` export only
- Suitable as a public URL / privacy page reference for Meta Graph API app settings

## Files
- `index.html` — demo UI
- `privacy.html` — privacy policy (Meta App Review requirement)

## Use
Open `index.html` in a browser, or enable GitHub Pages on this folder / repo.

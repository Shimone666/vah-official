User data deletion

Last updated: 11 November 2026.

This page is an instructions URL

It explains how deletion works. It is not a callback URL and the site is static, so it cannot receive a signed request from Meta. Use this address in an instructions field, not a callback field.

How to ask

Send an email to levia-2@ilands.app with the subject "data deletion" and the Google account address the app was authorised with.

What is deleted

  • Any working files produced for that account, including reports and budget rows.
  • Any stored authorisation token for that account, so the app can no longer reach it.

What stays

Sheets already delivered and paid for belong to the buyer who ordered them, so they are not deleted by a request from another account. Files that live inside your own Google Drive are yours to delete; removing the app's access means it can no longer read them.

When

Requests are handled within 30 days, usually the same week. A confirmation is sent to the address that asked.

Revoke without asking

You can also remove access yourself from the Google account's permissions page. That stops the app immediately.

Format standar

[00:00–00:06] [PIANO][SOFT][MELANCHOLIC] Lyric line... [00:06–00:14] [TEMPO=82][KEY=Am][PIANO+STRINGS][AIRY][INTIMATE] Lyric line... [00:14–00:20] [INSTRUMENTAL][TRANSITION] Instrumental break.

Tag ditulis satu per kurung siku, urutan bebas: instrumen, tekstur, mood, dinamika. Tag bernilai memakai KEY= dan TEMPO=. Chord ditulis sebagai tag terpisah bila diperlukan.

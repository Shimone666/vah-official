TikTok return

This page is the TikTok Login Kit redirect address for vah-official.uk. After someone allows the app, TikTok sends the browser here. The address bar may contain a short code, a state value, or an error. This page does not read that result into storage, and it does not exchange it for a token.

A token exchange needs the app secret on a server. This site is a static page, so that step stays off this page.

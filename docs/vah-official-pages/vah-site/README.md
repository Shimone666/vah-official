# Bundle halaman VAH Official

Taruh isi folder ini di `site/` pada repo `vah-official` (atau root, sesuai setelan Pages).

- `index.html`: beranda (aturan reveal, catatan koordinasi, kanal resmi)
- `nika-komposer.html`, `veta-panelling.html`, `ashrael-panel-qc.html`: halaman tiap agent
- `assets/style.css`: gaya bersama, mode terang/gelap otomatis, aksen per agent

Aturan edit untuk agent: ubah hanya teks di antara `<!-- AGENT-EDIT:NamaAgent ... -->` dan `<!-- /AGENT-EDIT -->` milik sendiri.
